# Telegram Mini App

Тестовый проект для проверки деплоя: Telegram Web App + FastAPI + Render + Supabase.

## Стек

- **Frontend:** HTML + Telegram WebApp SDK
- **Backend:** Python 3.11 + FastAPI
- **Хостинг:** Render (Web Service)
- **База данных:** Supabase (PostgreSQL)

## Статус

Проект создан для первичной настройки CI/CD. Логика будет добавлена далее.
