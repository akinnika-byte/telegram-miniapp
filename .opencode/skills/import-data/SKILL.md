## Правила

- Персональные данные (ФИО, звания, права) в git **не коммитить** — репозиторий публичный.
- Файлы импорта держать вне репозитория (например, Downloads), содержимое читать через openpyxl.

## Способы

1. **Через API приложения** (рекомендуется; работает, даже если нет прямого доступа к БД):
   - сгенерировать подписанную initData админа (пример — `scripts/api_check.py`);
   - `POST /api/login` с кодом `6666`;
   - для каждой машины `POST /api/admin/vehicles/save` с полями:
     `plate, model, fuel_norm, motohour_norm, tank_capacity, vin, engine_no,
     chassis_no, driver_name, driver_rank, driver_position, driver_license, is_active`.
2. **SQL-файлом**: сгенерировать `INSERT ... ON CONFLICT (plate) DO UPDATE`,
   положить вне репозитория и передать пользователю для Supabase → SQL Editor.

## Сопоставление с ведомостью

- ГРЗ = первые 4 цифры колонки «Государственный регистрационный знак».
- Колонка «Права» = категории (B, C), сохраняется в `driver_license`.
- Нормы расхода новых машин заполняет техник роты (по умолчанию 0).
